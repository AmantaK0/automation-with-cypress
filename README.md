# Cypress Test Automation Project

This project contains automated UI tests for the nopCommerce demo website, implemented using **Cypress** with **JavaScript** and **Page Object Model (POM)** design pattern.

The framework follows Cypress best practices and avoids implicit waits, using assertions and interceptions instead.

## Tech Stack

- Cypress
- JavaScript (ES6)
- Page Object Model (POM)
- Git & GitHub
